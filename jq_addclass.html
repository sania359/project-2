jQuery Class Methods
addClass() • removeClass() • toggleClass()

What is addClass()?

The addClass() method adds one or more CSS classes to selected elements. It is used to apply styling dynamically and create interactive web pages.

What is removeClass()?

The removeClass() method removes an existing class from an element. It restores the original appearance after interaction.

What is toggleClass()?

The toggleClass() method adds the class if it doesn't exist and removes it if it already exists. It is useful for menus, dark mode and many UI effects.
